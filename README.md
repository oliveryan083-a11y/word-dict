# 单词小词典 · 设计说明

> 版本：v1.0　日期：2026-08-25　作者：杨总 + Claude Code

## 一、背景与目标

杨总想给小学生（及成长中的孩子）做一个日常查单词用的词典网页，界面参考《牛津高阶英汉双解词典》App 的单词页（参考图：单词 July）。目标：孩子打开网页、输入单词，就能看到中文释义、音标、听发音、看例句，操作简单、界面可爱，手机和电脑都能用。

## 二、已确认需求（最终版）

| # | 需求 | 说明 |
|---|------|------|
| 1 | 网页版 | 浏览器打开即用，无需安装、无需联网 |
| 2 | 响应式 | 手机、电脑、平板都要好用 |
| 3 | 内置词库 | 覆盖小学到大学四六级，约 6000 词，离线可用 |
| 4 | 发音 | 区分英式 / 美式，各一个播放按钮 |
| 5 | 双向查询 | 英文→中文，中文→英文 |
| 6 | 界面风格 | 卡通童趣风：暖橙 + 奶油色、大圆角卡片、emoji、大字 |
| 7 | 例句 | 用带例句的开源数据源补充 |
| 8 | 技术方案 | 分离式：界面 / 样式 / 逻辑 / 词库分文件 |

## 三、技术架构

纯静态网页，**无需服务器**，共 4 个文件放在同一文件夹：

| 文件 | 作用 | 类比 |
|------|------|------|
| `index.html` | 页面结构 | 建筑外墙和房间布局 |
| `style.css` | 配色、圆角、字体、响应式 | 室内装修和配色 |
| `dict.js` | 查询逻辑、发音、双向索引 | 水电线路，藏在墙里 |
| `dict.json` | 词库数据（约 6000 词） | 家具清单，可随时增删 |

技术要点：
- 纯 HTML + CSS + JavaScript，**不用任何框架**，双击 `index.html` 即可打开。
- 打开时把词库加载进浏览器内存，建立查询索引，查询毫秒级响应。

│  ┌───────────────────────────┐  │
│  │ 🔍 输入单词，回车查询       │  │
│  └───────────────────────────┘  │
│  ┌───────────────────────────┐  │
│  │  🔤 July                   │  │
│  │  [dʒuˈlaɪ]     英 🔊  美 🔊       │
│  │                            │  │
│  │  📖 七月 · 名词(n.)         │  │
│  │                            │  │
│  │  💬 例句：                  │  │
│  │  The new model will be     │  │

│  │  （新型号产品将在七月推出。）│  │

- 主色调：暖橙（按钮、标题）+ 奶油白（卡片底），圆角大、字体大、行距宽。
- 搜索结果卡片居中，手机单列、电脑适当加宽。
- 空状态（未查询时）显示一句俏皮提示，如「输入一个单词试试吧 🎈」。

## 五、功能详述

### 5.1 双向查询
- **英文→中文**：输入英文（如 `July`），精确匹配词库的"单词"字段；若无精确匹配，做前缀匹配（输 `ju` 提示 `July`、`June`、`July` 等），并支持拼写近似建议。
- **中文→英文**：输入中文（如 `七月`），匹配词库的"中文释义"字段，返回所有释义含该词的单词列表（精确匹配优先，包含匹配次之）。

### 5.2 发音（英式 / 美式）
- 结果页显示两个喇叭按钮：「英 🔊」「美 🔊」。
- 点"英"用浏览器英式语音引擎（en-GB）朗读，点"美"用美式引擎（en-US）。
- 发音不联网、免费。

### 5.3 结果显示字段
单词、音标（首版一套，英式为主）、中文释义、词性、例句 + 例句翻译、词形变化、重要度星级。

### 5.4 友好提示
- 查不到时显示「没找到这个单词 😢，要不要检查一下拼写？」
- 对拼写接近的词给出建议。

## 六、词库数据结构（dict.json）

每个词一条记录，JSON 格式，字段如下：

```json
{
  "word": "July",
  "phonetic": "[dʒuˈlaɪ]",
  "translation": "七月",
  "pos": "n.",
  "exchange": "s:Julys",
  "star": 1,
  "tag": "gk",
  "example": "The new model will be launched in July.",
  "example_cn": "新型号产品将在七月推出。"
}
```

| 字段 | 含义 | 来源 |
|------|------|------|
| `word` | 单词 | ECDICT |
| `phonetic` | 音标（首版一套，英式为主） | ECDICT |
| `translation` | 中文释义 | ECDICT |
| `pos` | 词性 | ECDICT |
| `exchange` | 词形变化（复数/过去式等，如 `s:Julys`） | ECDICT |
| `star` | 重要度星级（1–5，由柯林斯星级换算） | ECDICT collins |
| `tag` | 考试范围（小学/初中/高中/四六级） | ECDICT tag |
| `example` | 英文例句 | 待补充数据源 |
| `example_cn` | 例句中文翻译 | 待补充数据源 |

## 七、数据来源与处理

1. **主体词库**：ECDICT 开源词库（约 77 万词），筛选出 tag 含小学/初中/高中/CET4/CET6 的词条，约 6000 词，提取上表字段。
2. **例句**：需调研一个**带例句的开源英语词库数据源**，与 ECDICT 按"单词"字段合并，填入 `example` / `example_cn`。
3. **音标**：以英式音标（DJ 音标，与中国中小学英语教材一致）为主，首版标一套。英式/美式的**发音**仍分两个按钮（分别用 en-GB / en-US 语音引擎）。实现时需验证 ECDICT 的音标是否为英式，若不是则改用英式音标数据源。后续若拿到英美两套音标，再分列显示。
4. **考频**：不需要。界面只显示重要度星级，不显示考频和词频排名。

## 八、数据缺口与降级方案

| 缺口 | 降级方案 |
|------|---------|
| 例句数据源找不到合适的 | 例句字段首版留空，界面隐藏例句区块，第二期再补 |
| 英美两套音标数据没有 | 音标只显示英式一套，发音仍分英美 |

## 九、验收标准

做完后按以下标准验收：
1. 双击 `index.html` 能打开，无需联网、无需装任何软件。
2. 输入 `July` 能看到中文释义、音标、词性、例句、复数、星级。
3. 点「英」和「美」能听到两种不同口音的发音。
4. 输入中文「七月」能反查出 `July`。
5. 手机和电脑上界面都正常、字大、好看。
6. 输入不存在的词（如 `asdfgh`）显示友好提示，不报错。
